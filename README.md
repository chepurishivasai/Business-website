
# Business Website (UGC Portal Clone)

## Description
This project is a responsive business/government-style website inspired by the University Grants Commission (UGC) portal. It is designed to provide a clean and structured interface for displaying organizational information, services, and initiatives.

---

## Features
- Responsive navigation bar with multiple sections  
- Home, About, Organisation, Guidelines, and Contact pages  
- Clean and modern UI design  
- Structured layout for government/business websites  
- Multiple pages with proper navigation  
- Mobile-friendly design  

---

## Technologies Used
- HTML5  
- CSS3  
- Bootstrap  
- JavaScript  

---

## Pages Included
- Home page  
- About Us  
- Organisation  
- Guidelines  
- Contact Us  
- Additional sections like e-Publications and Regulations  

---

## How to Run
1. Download or clone the repository  
2. Open `index.html` (or `main.html`) in your browser  

---

## Project Structure
- index.html / main.html → Main homepage  
- *.html → Different pages  
- *.css → Styling files  
- assets/images → Images and resources (if used)
